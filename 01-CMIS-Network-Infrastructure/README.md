# CMIS — Network & IT Infrastructure

**Project type:** Team project  
## Team Members

- **Ramakant Joshi**
- **Jonas Larsen**

This was a collaborative two-person project. We worked together on the design, implementation and testing of the proposed IT infrastructure. The project report documents the overall solution developed by our team.
**Environment:** Cisco Packet Tracer, Windows Server 2022, Windows 10 Pro

## Project Overview

This collaborative project focused on designing and implementing an IT infrastructure for a company expanding its operations from Copenhagen to Aarhus. The work covered network design, IP addressing, routing, Windows Server services, user management and connectivity verification.

## Technical Areas

### 1. Network Infrastructure
- Network topology design using Cisco Packet Tracer
- IP addressing and VLSM subnetting
- DHCP configuration and inter-network communication
- Routing and IP helper configuration

### 2. Windows Server Administration
- Windows Server 2022 configuration
- Active Directory Domain Services
- DNS configuration and domain services
- User and group management
- File shares and access permissions

### 3. Security and Access Management
- Group Policy configuration
- Access permissions and user access testing
- SSH configuration and verification

### 4. Testing and Troubleshooting
- Ping tests to verify connectivity
- Traceroute tests to examine network paths
- SSH connectivity verification
- Domain login and Group Policy verification
- File access and permission testing
